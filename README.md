# 合同会社サンアローズ Webサイト納品ファイル

このフォルダには、Cloudflare Pages などの静的ホスティングへ配置しやすい **単一HTML版** のWebサイトを収録しています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ブラッシュアップ済みの企業サイト本体です。CSSはHTML内に含めています。 |

## 反映内容

提供コードをもとに、企業サイトとしての信頼性と太陽光発電事業らしい先進性を高めるため、**Swiss International Style × Solar Tech Minimalism** の方針でデザインを再構成しました。具体的には、チャコールとアイボリーを基調に、太陽光を想起させるアンバーを限定的に使い、斜めの光線モチーフと大きな余白で発電インフラの安定感を表現しています。

| 項目 | 対応内容 |
|---|---|
| デザイン | ヒーロー、事業内容、会社概要を再設計し、企業サイトとして洗練された構成へ変更しました。 |
| 文章 | 中途半端な改行を避け、読みやすい段落に調整しました。必要な説明文も追加しています。 |
| コンタクトフォーム | 指示どおり作成していません。 |
| 代表者写真枠 | 指示どおり作成していません。 |
| 画像 | 太陽光発電事業に合う専用ビジュアルを使用しています。 |
| デプロイ | `index.html` のみで表示できるため、Cloudflare Pages に配置しやすい構成です。 |

## Cloudflare Pagesでの利用方法

1. `index.html` を含むフォルダを用意します。
2. Cloudflare Pages のプロジェクト作成画面で、静的サイトとしてアップロードまたはGit連携します。
3. ビルドコマンドは不要です。
4. 出力ディレクトリ指定が必要な場合は、`/` またはアップロードしたフォルダのルートを指定してください。

## 編集時の注意

会社情報や事業説明を変更する場合は、`index.html` 内の該当テキストを直接編集してください。デザイン全体のトーンを保つため、色は `:root` 内のCSS変数を変更するのがおすすめです。
